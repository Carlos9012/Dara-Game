### Dica de mestre:
Como o seu ambiente virtual chama-se `.venv` (com ponto no início), o comando manual simples no PowerShell seria:
`.\.venv\Scripts\Activate.ps1`

Mas o comando que você usou é mais seguro pois ignora as travas de segurança do Windows temporariamente para essa janela! Se precisar de mais alguma ajuda com o código do Dara, é só chamar.
